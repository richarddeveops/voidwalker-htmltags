HTML ASSIGNMENT: SELF-CLOSING TAGS
===================================

What is a self-closing tag? 
----------------------------
In HTML, the more accurate name is a void element. It does not contain text
or another element, so it does not need a separate closing tag.

Example from the assignment:
    <br>

The slash form is also commonly written:
    <br />

In normal HTML, both forms work. The slash is required for XML-style syntax,
but it is not required for HTML void elements.

HOW TO EXPLAIN THE DIFFERENCE IN CLASS
--------------------------------------
Container tag example:
    <p>This is a paragraph.</p>

A container tag has an opening tag, content, and a closing tag.

Void/self-closing tag example:
    <br>

A void tag has no content and no closing tag. It performs an action or adds
an object directly to the page.

One correction to mention:
- <command>, <keygen>, <menuitem>, and <param> are old/obsolete elements.
- The SVG examples are valid SVG empty elements, but they are not ordinary
  HTML void elements.
- In modern HTML, use <button> or another current control instead of the
  obsolete command-style elements.
