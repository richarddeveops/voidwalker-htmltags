HTML Void and SVG Elements

This assignment shows 40 element names as code examples: 17 HTML entries and 23 SVG entries.

HTML void-element examples

A void element has no child content and no closing tag. Some names in this historical practice list are obsolete, so they are shown as text rather than used as active HTML.

  1. <br> line break
  2. <img> image
  3. <hr> thematic break
  4. <input> form control
  5. <meta> document metadata
  6. <link> external resource link
  7. <area> image-map area
  8. <base> base URL
  9. <col> table column settings
  10. <embed> embedded content
  11. <source> media source
  12. <track> timed text track
  13. <param> obsolete object parameter
  14. <wbr> optional word-break position
  15. <command> obsolete command element
  16. <keygen> obsolete key-pair control
  17. <menuitem> obsolete menu item
