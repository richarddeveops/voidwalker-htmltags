HTML TAGS AND ELEMENTS

A tag is the markup inside angle brackets, such as <p>. An element is the complete structure: usually an opening tag, content, and a closing tag. Attributes add information to an element, for example href on a link or src and alt on an image.

I practised headings, paragraphs, buttons, spans, links, and images. Container elements such as <p> contain content; void elements such as <img> do not have closing tags. HTML comments can leave notes in the source without displaying them on the page.

Use lowercase tag and attribute names and quote attribute values for consistent, readable markup.
